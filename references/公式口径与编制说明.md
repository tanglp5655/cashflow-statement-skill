# 公式口径与编制说明

本文档逐条对照模板《编制现金流量表2024.xls》的实际公式，供引擎实现与核对使用。
所有公式均提取自模板工作表的单元格公式，口径以模板为准。

## 一、编制原理（摘自《现金流量表编制说明.txt》）

> 本现金流量编制办法主要是根据资产负债表、利润及利润分配表各帐户的变动情况进行分析，
> 并补充若干表外数据，然后将这些科目的分析结果分别归入现金流量表的各项目，以此自动生成现金流量表。

- 只录入数据、不处理平衡：报表平衡问题在公式设置中已考虑，无须担心。
- 主表正表不能出现负数：现金流入栏为负 → 以正数填入对应项目的现金流出栏（编制说明第四条）。
- 本表只能反映大致基本状况，供对外使用；公司决策须按明细账簿另行编制。

## 二、主表公式（现金流量表工作表，C列金额，直接法）

以下行次对应模板布局（1-based 行号）：

| 主表项目 | 行次 | 模板公式（已整理） |
| --- | --- | --- |
| 销售商品、提供劳务收到的现金 | 1 | `利润表营业收入×1.13 + (应收票据年初-期末) + (应收账款年初-期末) + (预收款项期末-年初) - 表外应收票据贴现利息支出` |
| 收到的税费返还 | 3 | `(应收补贴款年初-期末) + 利润表补贴收入` |
| 收到的其他与经营活动有关的现金 | 8 | **平衡项**：`现金净增加额 + 经营现金流出小计 - 销售商品收到现金 - 收到税费返还 - 投资活动净额 - 筹资活动净额 - 汇率影响` |
| 现金流入小计 | 9 | 上述三项之和 |
| 购买商品、接受劳务支付的现金 | 10 | `(营业成本 + 存货期末-年初)×1.17 + (应付票据年初-期末) + (应付账款年初-期末) + (预付款项期末-年初)` |
| 支付给职工以及为职工支付的现金 | 12 | 表外"支付给职工的工资+四金+其他福利费"合计 |
| 支付的各项税费 | 13 | `应交增值税+其他各项税+所得税+管理费用中列支的税金+其他业务支出中列支的税金 - (应交税费+其他应交款期末-年初)` |
| 支付的其他与经营活动有关的现金 | 18 | 模板为手工/平衡区，引擎默认0并可由用户通过表外数据覆盖 |
| 现金流出小计 | 20 | 上述四项之和 |
| 经营活动产生的现金流量净额 | 21 | 现金流入小计 − 现金流出小计 |
| 收回投资所收到的现金 | 22 | 手工（表外），默认0 |
| 取得投资收益所收到的现金 | 23 | 表外"收到投资分红或利润" |
| 处置固定资产、无形资产和其他长期资产而收到的现金净额 | 25 | 表外处置三项现金净额合计 |
| 收到的其他与投资活动有关的现金 | 28 | 表外录入 |
| 购建固定资产、无形资产和其他长期资产所支付的现金 | 30 | `(固定资产+工程物资+在建工程+无形资产+长期待摊费用+其他长期资产)期末-年初` |
| 投资所支付的现金 | 31 | `(短期投资+长期股权投资+长期债权投资)期末-年初` |
| 支付的其他与投资活动有关的现金 | 35 | 表外录入 |
| 吸收投资所收到的现金 | 38 | `实收资本期末-年初` |
| 借款所收到的现金 | 40 | `(短期借款+长期借款+应付债券+长期应付款+专项应付款+其他长期负债)期末-年初` |
| 收到的其他与筹资活动有关的现金 | 43 | 手工（表外），默认0 |
| 偿还债务所支付的现金 | 45 | 手工（表外），默认0 |
| 分配股利、利润或偿付利息所支付的现金 | 46 | 表外"分配股利+分配利润+利息支出" |
| 支付的其他与筹资活动有关的现金 | 52 | 手工（表外），默认0 |
| 汇率变动对现金的影响 | 55 | 手工，默认0 |
| 现金及现金等价物净增加额 | 56 | 经营+投资+筹资净额+汇率 |

| 补充资料项目 | 行次 | 模板公式 |
| --- | --- | --- |
| 净利润 | 57 | 利润表净利润 |
| 加：计提的资产减值准备 | 58 | 表外"计提的坏账准备"（手工录入，模板不自动估算） |
| 固定资产折旧 | 59 | `累计折旧期末-年初` |
| 无形资产摊销 | 60 | 表外录入 |
| 长期待摊费用摊销 | 61 | 表外录入 |
| 待摊费用减少（减：增加） | 64 | `待摊费用年初-期末` |
| 预提费用增加（减：减少） | 65 | `预提费用期末-年初` |
| 处置固定资产等损失（减：收益） | 66 | 利润表营业外支出（模板近似） |
| 固定资产报废损失 | 67 | 表外录入 |
| 财务费用 | 68 | 表外"利息支出"（不抵减利息收入） |
| 投资损失（减：收益） | 69 | `-利润表投资收益` |
| 递延税款贷项（减：借项） | 70 | `(递延税项贷项期末-年初) - (递延税款借项期末-年初)` |
| 存货的减少（减：增加） | 71 | `存货年初-期末` |
| 经营性应收项目的减少（减：增加） | 72 | `(应收票据+应收股利+应收利息+应收账款+其他应收款+预付款项+应收补贴款)年初-期末` |
| 经营性应付项目的增加（减：减少） | 73 | `(应付票据+应付账款+预收款项+应付职工薪酬+应付福利费+应付股利+应交税费+其他应交款+其他应付款+预提费用)期末-年初` |
| 其他 | 74 | 倒挤项：`主表经营净额 - 以上各项之和`（保证与主表一致） |
| 经营活动产生的现金流量净额 | 75 | 以上各项之和 |

## 四、表外数据自动推算规则（模板公式）

| 表外项目 | 模板公式 |
| --- | --- |
| 支付给职工的四金 | `支付给职工的工资 × 26.6%`（可按实际修改） |
| 支付给职工的其他福利费 | `支付给职工的工资 × 1.06%` |
| 销项税额 | `利润表营业收入 × 销项税率`（模板默认 6%，须按实际修改） |
| 进项税额 | `(利润表营业成本 + 存货期末-年初) × 进项税率` |
| 应交增值税 | `销项税额 - 进项税额` |
| 其他各项税 | 利润表营业税金及附加 |
| 所得税 | 利润表所得税费用 |
| 实际应缴纳各项税金合计 | `应交增值税+其他各项税+所得税+管理税金+其他业务税金 - (应交税费+其他应交款期末-年初)` |
| 分配股利、利润或偿付利息所支付的现金 | `分配股利 + 分配利润 + 利息支出` |
| 处置固定资产、无形资产和其他长期资产所收回的现金净额合计 | `处置固定资产 + 处置无形资产 + 处置其他长期资产` |

## 五、负数调整规则（编制说明第四条）

主表正表不得出现负数，自动调整规则（与编制说明示例一致）：

| 出现负数的流入项 | 转入的流出项 |
| --- | --- |
| 销售商品、提供劳务收到的现金 | 购买商品、接受劳务支付的现金 |
| 投资所支付的现金 | 收回投资所收到的现金 |
| 购建固定资产、无形资产和其他长期资产所支付的现金 | 处置固定资产、无形资产和其他长期资产所收回的现金净额 |
| 借款所收到的现金 | 偿还债务所支付的现金 |
| 吸收投资所收到的现金 | 支付的其他与筹资活动有关的现金 |
| 分配股利、利润或偿付利息所支付的现金 | 借款所收到的现金 |
| 收到的其他与经营活动有关的现金（平衡项） | 支付的其他与经营活动有关的现金 |

## 六、勾稽关系（引擎自动校验）

1. 资产负债表：资产总计 = 负债及所有者权益总计（年初/期末）
2. 经营活动现金流量净额：主表（直接法）= 补充资料（间接法）
3. 现金及现金等价物净增加额 = 货币资金（+现金等价物）期末-期初
4. 未分配利润增加 ≈ 本年净利润（差异通常为利润分配，提示用）

## 七、模板参数默认值（可按实际修改）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| sale_vat_rate | 0.13 | 销售商品含税换算：营业收入×(1+13%) |
| purchase_vat_rate | 0.17 | 购货含税换算：营业成本×(1+17%) |
| extra_sale_tax_rate | 0.06 | 表外销项税额适用税率（模板默认6%） |
| extra_pur_tax_rate | 0.06 | 表外进项税额适用税率 |
| four_gold_rate | 0.266 | 支付给职工的四金比例 |
| welfare_rate | 0.0106 | 支付给职工的其他福利费比例 |
| bad_debt_rate | 0.005 | 计提坏账准备比率（模板默认0.5%，仅供录入参考） |

> 提示：模板为通用格式，各比例/税率均按编制说明要求"须按公司实际情况修改"。
> 引擎提供 `--json-params` 参数覆盖（见 SKILL.md）。
