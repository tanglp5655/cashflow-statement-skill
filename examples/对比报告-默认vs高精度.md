# 默认模式 vs 高精度模式 —— 演示对比

**样本**：示例制造企业（口径干净：无金融业务、无大额理财）
**经营净额真值**：655.00 万元

## 对比结果

| 项目 | 默认模式 | 高精度模式 | 真值 |
| --- | ---: | ---: | ---: |
| 销售商品收到现金 | 6,854.00万 | 6,055.00万 | 6,055.00万 |
| 收到税费返还 | 0.00万 | 20.00万 | 20.00万 |
| 购买商品支付现金 | 4,620.40万 | 4,250.00万 | 4,250.00万 |
| 支付给职工 | 680.00万 | 680.00万 | 680.00万 |
| 支付的各项税费 | 10.00万 | 230.00万 | 230.00万 |
| **经营活动现金流量净额** | **890.00万** | **655.00万** | **655.00万** |
| **净额误差** | **+35.88%** | **+0.00%** | — |

## 结论

1. **默认模式**：经营净额靠"货币资金变动"倒挤 → 误差 +35.88%
2. **高精度模式**：填现金流量表主表真实值（关键项"收到的其他与经营活动有关的现金"）→
   经营净额 = 各项真实值之和 → 误差 **+0.00%**
3. 只要企业业务口径干净（无金融业务混入、货币资金≈现金等价物），高精度模式可精确到 0

## 实操指引

- 日常测算/对外报数 → 默认模式（或补表外数据）即可
- 重要报表（银行授信/税务/决策）→ 用高精度模式，从自己现金流量表主表抄 6-8 个数
