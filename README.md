# 现金流量表自动编制 Skill

依据 **资产负债表 + 利润及利润分配表（损益表）+ 少量表外数据**，自动编制现金流量表。
公式口径严格取自模板《编制现金流量表2024.xls》与《现金流量表编制说明.txt》：
**直接法编制主表 + 间接法编制补充资料**，自动归集经营活动 / 投资活动 / 筹资活动三大类现金流。

**作者**：四川金沐志德科技有限公司

> 📖 **新手请先看 [使用手册](https://github.com/tanglp5655/cashflow-statement-skill/blob/main/USER_GUIDE.md)**——含两种使用场景（AI 助手对话 / 命令行）、
> 数据准备指南、填表说明、常见问题 FAQ。

## 快速开始

### 方式一：单工作簿（最省事）

Excel 工作簿内含"资产负债表 / 利润及利润分配表 / 表外数据录入"三个工作表时（模板即此结构），
只传一个文件即可：

```bash
pip install openpyxl xlrd          # 仅解析 Excel 时需要
python scripts/cash_flow_generator.py --bs 编制现金流量表2024.xls --out output --fmt all
```

### 方式二：三张表分开

```bash
python scripts/cash_flow_generator.py \
  --bs 资产负债表.xlsx --pl 利润表.xlsx --extra 表外数据.xlsx \
  --out output --fmt all
```

支持格式：`.xlsx` / `.xls` / `.csv`（UTF-8 或 GBK） / 粘贴的 Markdown 表格文本。
三个输入参数均可直接传表格文本，脚本自动识别。

### 表外数据收集表（强烈推荐）

`examples/表外数据收集表.xlsx`（含 .csv 版）是提升精度的关键工具——只需填写
**"支付给职工的工资"**（必填）及其他你能拿到的真实数据（税费、折旧、摊销、处置损益等），
作为 `--extra` 传入即可，其余留空引擎自动推算：

```bash
python scripts/cash_flow_generator.py \
  --bs 资产负债表.xlsx --pl 利润表.xlsx --extra examples/表外数据收集表.xlsx \
  --out output --fmt all
```

> 精度实测：表外数据齐全时，销售商品收到现金等流入项误差 ±7% 以内；经营净额在主表口径
> 由货币资金变动倒挤平衡，若企业有大量定期存款/理财（货币资金≠现金等价物）会系统性偏差，
> 请以现金流量表附注为准（详见 `references/验证报告-三一重工2025.md`）。

### 怎么把误差压到最小（高精度模式）

收集表第二区可填**现金流量表主表真实值**（销售收到现金、购买支付、支付职工、税费、
收到其他经营现金等）。关键：**填了"收到的其他与经营活动有关的现金"即关闭倒挤开关**，
经营净额 = 各项真实值之和，彻底摆脱"货币资金≠现金等价物"的干扰。
实测三一重工 2025 真实值填齐后误差 **+0.00%**。

```
误差层级：默认模式 ±7%~20% → 补表外数据 ±5% → 高精度模式 ±0%
```

```bash
python scripts/cash_flow_generator.py --bs bs.xlsx --pl pl.xlsx --extra extra.xlsx \

```

### 英文输出

加 `--lang en` 即可输出全英文报表（项目名/表头/标题/附注标签均翻译）：

```bash
python scripts/cash_flow_generator.py --bs 报表.xlsx --out output --fmt all --lang en
# 输出: Cash_Flow_Statement.md / .xlsx / .docx / .json
```

> 注意：英文模式仅翻译输出层文本，报表格式仍为中国《企业会计制度》口径，
> 尚未适配 IFRS/US GAAP 的行次结构。

## 输出

| 文件 | 内容 |
| --- | --- |
| `现金流量表.md` | 规范主表（行次/本期/上期金额）+ 补充资料 + 现金及现金等价物 + 负数调整说明 + 勾稽校验 + 编制附注 |
| `现金流量表.xlsx` | 分工作表：主表、补充资料、编制附注与校验 |
| `现金流量表.docx` | **Word 年报格式**（适合银行/税务/老板，可直接打印） |
| `现金流量表.json` | 结构化结果，便于程序化处理 |

> `--fmt` 可选 `markdown` / `excel` / `word` / `json` / `all`（全部）。
> Word 输出需 `pip install python-docx`。

## 核心口径（摘要，详见 `references/公式口径与编制说明.md`）

- **销售商品、提供劳务收到的现金** = 营业收入×(1+销项税率) + (应收票据年初−期末) + (应收账款年初−期末) + (预收款项期末−年初) − 贴现利息
- **购买商品、接受劳务支付的现金** = (营业成本+存货期末−年初)×(1+进项税率) + (应付票据年初−期末) + (应付账款年初−期末) + (预付款项期末−年初)
- **支付的各项税费** = 应交增值税+其他各项税+所得税+管理税金+其他业务税金 − (应交税费+其他应交款期末−年初)
- **收到的其他与经营活动有关的现金** = 平衡项自动倒挤（保证主表平衡）
- **补充资料**：净利润 → +资产减值准备 +折旧 +摊销 ±待摊/预提 ±处置损失 ±财务费用 ±投资损失 ±递延税款 ±存货/经营性应收/应付变动 → 经营活动现金流量净额（"其他"为倒挤项）
- **负数调整**（编制说明第四条）：主表正表不得为负数，流入为负自动移入对应流出项

## 参数覆盖（税率/比例按公司实际修改）

```bash
python scripts/cash_flow_generator.py --bs 报表.xlsx \
  --json-params '{"sale_vat_rate":0.09, "extra_sale_tax_rate":0.06, "four_gold_rate":0.2}'
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `sale_vat_rate` | 0.13 | 销售含税换算 |
| `purchase_vat_rate` | 0.17 | 购货含税换算 |
| `extra_sale_tax_rate` | 0.06 | 表外销项税额税率 |
| `extra_pur_tax_rate` | 0.06 | 表外进项税额税率 |
| `four_gold_rate` | 0.266 | 职工四金比例 |
| `welfare_rate` | 0.0106 | 职工其他福利费比例 |
| `bad_debt_rate` | 0.005 | 计提坏账比率（供参考） |

## 重要提示

- 本表反映现金流量**大致基本状况**，仅供对外使用；公司决策须按明细账簿另行编制（编制说明原文）。
- 税率与坏账计提比例**须按公司实际情况修改**。
- 表外数据缺失时引擎按模板比例自动推算（工资→四金26.6%、福利费1.06%；销项/进项税按税率推算），并在附注中标注。
